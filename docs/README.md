# MoonLight Language – Quick Start Guide

> **NOTE**
> This guide provides a concise introduction to the MoonLight programming language, its syntax, and how to compile/run code targeting both CPU and GPU.

---
## What is MoonLight?
MoonLight is a high‑level language that combines familiar Python‑like syntax with first‑class support for GPU programming (CUDA) and advanced features such as pipelines, work queues, and async/await. It compiles to C/C++/CUDA via a custom compiler (`moonc`) and can be executed directly with the REPL (`repl.py`).

## Basic Syntax Overview
| Construct | Example | Description |
|-----------|---------|-------------|
| **Variable assignment** | `x = 42` | Assigns a value to a variable. |
| **Function definition** | `def add(a, b) { return a + b }` | Defines a function. |
| **If/else** | `if (x > 0) { print("positive") } else { print("non‑positive") }` | Conditional execution. |
| **Loop** | `for i in range(5) { print(i) }` | Classic `for` loop. |
| **GPU kernel** | `gpu[256, 256] vec_add(a, b, c) { c[i] = a[i] + b[i]; }` | Defines a CUDA kernel. |
| **Pipeline** | `pipeline my_pipe { stage load: load_data(); stage compute: compute_kernel(); stage save: save_results(); }` | Declares a pipeline of stages. |
| **Work queue** | `q = gpu_queue[Task, 10]` | Creates a GPU work queue with capacity 10. |
| **Async/await** | `async def fetch() { await io_read(); }` | Asynchronous function. |

## Compiling a GPU Kernel
Create `vector_add.gpu`:
```moon
gpu[256, 256] vec_add(a, b, c) {
    c[threadIdx_x] = a[threadIdx_x] + b[threadIdx_x];
}
```
Compile and run:
```bash
python -m moonc vector_add.gpu   # Generates C++/CUDA source and builds it
./vector_add                     # Executes the compiled binary
```
The compiler automatically links against the MoonLight runtime library (`moonlight_runtime.h`).
