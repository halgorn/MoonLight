## 🚀 COMO USAR

### Instalação
```bash
git clone https://github.com/moonlight-lang/moonlight.git
cd moonlight
pip install -r requirements.txt
```

### Executar Programa
```bash
# Modo interpretado (rápido)
python moonc.py programa.gpu -r

# Compilar para executável
python moonc.py programa.gpu -o app
./app
```

### REPL Interativo
```bash
python repl.py

moon> x = 10
moon> y = x * 2
moon> print(y)
20
moon> exit
```

### Debugger
```bash
python debugger.py

(moon-db) b 15
(moon-db) c
(moon-db) p variavel
(moon-db) q
```

### Package Manager
```bash
python moonpkg.py install moonlight-utils
python moonpkg.py list
```
